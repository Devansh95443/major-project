# Modern Chatbot Application

A full-stack chatbot application built with React and Node.js. This project demonstrates a modern, responsive chatbot interface with real-time messaging capabilities.

## Features

- Real-time chat interface
- Modern and responsive design
- Message history
- User-friendly interface
- Easy to customize and extend

## Tech Stack

- Frontend:
  - React
  - TypeScript
  - Tailwind CSS
  - Socket.io-client

- Backend:
  - Node.js
  - Express
  - Socket.io
  - TypeScript

## Project Structure

```
major-project/

├── .gitignore

```

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/Devansh95443/major-project.git
   cd major-project
   ```

2. Install dependencies for both frontend and backend:
   ```bash
   # Install frontend dependencies
   cd client
   npm install

   # Install backend dependencies
   cd ../server
   npm install
   ```

3. Start the development servers:
   ```bash
   # Start backend server (from server directory)
   npm run dev

   # Start frontend server (from client directory)
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` to view the application.
